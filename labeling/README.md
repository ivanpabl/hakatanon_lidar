# Ручная разметка препятствий

Цель — эталон, по которому считаются ложные тревоги и пропуски детектора.
Размечается **сцена**, а не тревоги: какие посторонние объекты реально есть на
пути и где. Поэтому разметка остаётся верной для любой будущей версии детектора.

## Что в наборе

- каждый 10-й кадр всех записей (`new_data` и 6 записей из `Датасет`);
- плюс по одному кадру от коротких тревог детектора, проскочивших между шагами;
- 40 **калибровочных** кадров — одинаковые у всех участников;
- 12 % **перекрытия** — начало участка соседа, чтобы каждый такой кадр размечали двое.

## Подготовка (один раз, делает тот, у кого лежат данные)

```bash
python labeling/make_set.py render --bag new_data            # можно параллельно по --range
python labeling/make_set.py render --bag doubleT_obstacle    # и остальные записи
python labeling/make_set.py split --participants 4
```

Получаются папки `data/labeling/participant_1` … `participant_4`. Каждую нужно заархивировать и отдать своему участнику.

## Как размечать (участник)

1. Распаковать папку, открыть `index.html` в браузере (Chrome/Firefox).
2. **Сначала калибровка** (синяя метка «калибровка»): после неё сверить ответы
   всей командой и договориться о спорных случаях. Только потом — свой участок.
3. На каждом кадре:
   - **Пусто** `1` — в коридоре (до ~1,5 м от оси пути, выше головки рельса) нет посторонних объектов;
   - **Препятствие** `2` — есть: кликнуть по объекту на одной из двух левых
     панелей (запишется дальность и смещение от оси); тип выбирается клавишами
     `Q` предмет, `W` человек, `E` техника, `R` другое;
   - **Неясно** `3` — и пару слов в комментарии.
   - `A` — линия оси пути на виде сверху явно не на пути.
   - `←`/`→` — назад/вперёд, `N` — к следующему неразмеченному, `Backspace` — убрать последний клик.
4. Разметка сама сохраняется в браузере. В конце (и на всякий случай по ходу) —
   **Сохранить CSV** и отправить файл `labels_participant_<k>.csv`.

### Как отличить настоящий объект

| Настоящий | Не препятствие |
|---|---|
| компактный кластер, отдельно от стен | продолжается в стену / платформу за краем коридора |
| **тень**: сразу за ним на полу нет точек | лежит вдоль края коридора или на рельсе |
| на профиле — «столбик» над нулём | «появляется» только в серой зоне (ось пути — догадка) |
| держится на соседних кадрах | скачет от кадра к кадру |

Серая зона на левых панелях — там ось пути не найдена, выпрямленный коридор
ненадёжен: сверяться с видом сверху (справа внизу).

## Сведение результатов

Положить все CSV в `data/labeling/results/` и запустить:

```bash
python labeling/merge.py data/labeling/results/*.csv
```

Скрипт печатает согласие на калибровке и перекрытии, список спорных кадров и
пишет `data/labeling/labels_merged.csv`. Спорные кадры разобрать вместе.
