## Как читать за 10 минут

1. [README](../README.md): ключевые цифры и запуск в три команды.
2. [algorithm.md](algorithm.md), разделы «Идея» и «Обработка кадра»: что происходит с кадром от облака до решения.
3. [experiments.md](experiments.md), раздел «Итог»: на чём и как измерено.
4. [hard_cases.md](hard_cases.md): где решение ошибается и что с этим сделано.

## Как проверить цифры самому

```bash
pip install -e "core[eval]"
python -m pytest -q tests                 # тесты ядра на синтетическом тоннеле, записи не нужны
python -m evaluation all --quick          # проверка окружения, пара минут
python -m evaluation all                  # полный прогон по записям из data/, около часа на 6 процессах
docker compose run --rm test              # gtest и pytest узлов внутри образа
```

Копии результатов финального прогона лежат в `evaluation/reference/`, страница отчёта собирается из них и без записей.
