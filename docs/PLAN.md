Дедлайн загрузки — 29.09 23:59 МСК. Сдаваемая версия — к вечеру 27.09.

## Исходное состояние (commit `ae38df6`)

- Ядро `core/tunnel_od`: рельсы → ось → продление по стенам → профиль полотна → зона → кластеры → «3 из 5».
- Есть, но выключено: остаток до фона в развёртке вдоль оси (`method='background'`), скорость поезда по сцене (`ego_motion=True`).
- Ложные тревоги: 14 % кадров пустых записей. Найдено (объекты от 0,4 м): 83 % до 40 м, 73 % на 40–80 м, 43 % на 80–130 м.
- **Нет ROS 2-узла, Docker, тестов** — без них решение не сдаётся (ТЗ §3.3, §8.1, §8.6).

## Решения

- Без обучения нейросетей: нет разметки, нет GPU, проверка на других тоннелях. Карту по прошлым проездам не строим по той же причине.
- Каждое изменение алгоритма включается по умолчанию, только если на бенчмарке растёт дальность или полнота и при этом не растут ложные тревоги.
- Главная метрика — **дальность первого подтверждённого обнаружения неподвижного объекта**, к которому поезд подъезжает (ТЗ §8.2), при ложных тревогах на `new_data` не выше базы.

## Задачи

### P0. Сдаваемость
1. ROS 2-узел `tunnel_od_detector` (rclpy): подписка на `PointCloud2` (топик по типу), `ObstacleDetector`, публикация результата (JSON в `std_msgs/String`) и маркеров для RViz. QoS reliable.
2. Dockerfile (`ros:humble`), `run.sh`, конфиг DDS для кадров 8–23 МБ, launch-файл.
3. e2e: `docker build → docker run → ros2 bag play` — обработано ≥ 95 % кадров, задержка < 100 мс.
4. `pytest` на ядро, README с инструкцией запуска.

### P1. Метрика «подъезд»
5. `tools/eval_approach.py`: объект неподвижен в мире, поезд подъезжает (смещение за кадр — по оценке скорости на кадрах без вставки). Выход: дальность первого подтверждения, доля найденных, ошибка дистанции, ложные тревоги на окне.
6. Базовые замеры: `zone` против `background`, `alarms.py` на 6 записях и `new_data`.

### P2. Алгоритм
7. Дальность просмотра `clear_to_m` вместо `path_margin`: минимум из надёжной оси, прямой видимости на кривой и конца видимого полотна. Тревоги только до неё, значение выводится.
8. Накопление свидетельства вместо «3 из 5»: прогноз трека по скорости поезда, кластеры меньше порога не выбрасываются, а копятся; порог — по сумме точек, нормированной на ожидаемую плотность.
9. Подбор порогов на части `new_data`, проверка на отложенной части.

### P3. Если останется время
10. Классификатор кандидатов на физических признаках (отрицательные — `new_data`).
11. RViz-демо, видео, презентация.
